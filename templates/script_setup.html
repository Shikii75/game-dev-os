Unity Component Assignment Registry

Complete directory of all C# scripts in the project, organized by feature area.

Script Name Target GameObject Inspector Assignments & Usage Instructions
⚔️ Player & Combat
move.cs Player Manages standard left/right movement, jumps, fast blob form (triggered by M), and rapid horizontal dashes (triggered by L-Shift). Receives slow debuffs.
health.cs Player / Enemies Tracks current/max health, processes taking damage (ignores damage if player is currently in a dash invulnerability state), handles healing, and triggers death events.
PlayerCurrency.cs Player Tracks coin balances and potion counts. Pressing H consumes a potion to heal. Spawns events for HUD refresh.
MageCombat.cs Player • Melee Attack Collider: Drag Player weapon swing trigger collider.
• Projectile Prefab: Assign the MagicProjectile prefab here.
• Projectile Spawn Point: Assign a child transform situated at the front of the Player.
MagicProjectile.cs Magic Projectile Prefab Requires a Rigidbody2D (Gravity: 0) and a BoxCollider2D (check Is Trigger). Propels spell bolts forward.
CoinItem.cs Coin Drop Prefab Requires CircleCollider2D (check Is Trigger) and Rigidbody2D. Magnetizes smoothly towards the Player when in range.
attack.cs Player (Original Melee) Original basic melee attack script mapping key J to trigger standard weapon swings. (Can be replaced by MageCombat.cs).
🕷️ Enemies & Bosses
EnemyPatrol2D.cs Advanced Patrol Enemies • Target A & B: Assign Player transforms.
• Patrol Point 1 & 2: Link waypoint transforms. Walks between points; chases, dashes, and slashes the player when they are in range. Supports knockback states.
BaseMob.cs Basic Patrol Enemies • Left Point & Right Point: Link patrol boundary transforms.
Basic horizontal patroller script. Flashes red on damage hit and destroys itself on death.
SpiderBoss.cs Arachnid Boss • Roam Points: Transforms of roam paths.
• Web Projectile Prefab & Spiderling Prefab: Assign web and spiderling prefabs.
Manages phase transitions (3 phases based on health thresholds) and boss attacks (ClawSwipe, WebSpray, Spawnlings, Stomp).
spiderpatrol.cs Spider Patrollers Basic cave spider patroller script. Moves back and forth between left/right margins.
EnemyPatrolAI.cs Patrol Enemy AI Legacy patroller AI script. Used for basic waypoint routing and player detection.
WebProjectile.cs Web Projectile Prefab Requires Rigidbody2D and Collider2D (check Is Trigger). Shot by Arachnid Boss; flies towards the player, deals damage, and applies a temporary movement speed slow.
Spiderling.cs Spiderling Prefab Requires Rigidbody2D and Collider2D. Mini spider spawned by boss; chases player aggressively, bites and explodes on contact. Implements IDamageable.
ArenaWaveManager.cs Arena Wave Trigger GameObject Requires BoxCollider2D (check Is Trigger). Link the Coin Prefab & Arena Lock Gates (doors). Set up spawn points and wave spawn settings to lock and trigger arena encounters.
ArenaDoorTransition.cs Arena Door GameObjects Arena Entrance Setup:
• Attach ArenaDoorTransition to the trigger collider in front of each arena door.
• For an entrance door: Set Destination Point to an empty GameObject inside the arena interior. Set Available Prompt Text to Press E to enter. Optional: add the exterior objects to Disable On Arrival and the interior objects to Enable On Arrival.
• For an exit door: Set Destination Point to an empty GameObject outside the arena door. Set Available Prompt Text to Press E to leave. Enable Requires Arena Cleared and assign the room's ArenaWaveManager if the player should not leave before finishing the fight. Optional: add the exterior objects to Enable On Arrival and the interior objects to Disable On Arrival.
• When the turnaround animation is ready, add a trigger parameter named TurnIn to the player Animator, or change Turn In Trigger on the door to match your trigger name.
ArenaTransitionFader.cs UI Transition Canvas Automatically instantiated screen fader utility. Renders full-screen black canvas overlay and interpolates alpha channel transparency to transition smoothly between exterior and interior arena segments.
🖥️ Systems & UI
UIFactory.cs N/A (Static Utility) ⚙️ CODE-GENERATED — Static helper class. Not attached to any GameObject.
Provides factory methods (CreateCanvas, CreatePanel, CreateText, CreateButton, CreateSlider) used by all UI scripts below to build consistent dark gothic-fantasy styled panels at runtime.
HUDManager.cs Empty GameObject (e.g. "HUD Manager") ⚙️ CODE-GENERATED — Builds its own Canvas and full HUD from code. No manual UI setup required.
• Player Game Object: (Optional) Drag Player here, or it auto-finds by tag.
• UI Scale Settings: Adjust size via hudScale float in the Inspector (defaults to 10 for 10x scaling).
• Creates health bar (red fill, top-left) and mana bar (blue-purple, below health) featuring custom gothic border frames, diamond-rotated prefix icons (H / M), dynamic under-fill damage sliders (lag/catch-up effect), dynamic notch markers (spaced every 25/20 points), and a flashing red low-health danger pulse. Coin and potion counters update on the top-right.
NPCDialogueUI.cs Dialogue Canvas (e.g. "Dialogue Manager") • UI References (Drag & Drop): Link the Dialogue Panel GameObject (designed in Pokémon or Hollow Knight bubble style) along with the TextMeshPro elements for NPC Name, Body Text, and Advance Indicator.
• Type Speed: Adjustable typewriter speed (default 0.02s).
• Handles resolution-adaptive canvas scaling automatically. Advances on click/E/Enter, closes on Escape.
ShopUI.cs Empty GameObject (e.g. "Shop UI Manager") ⚙️ CODE-GENERATED — Builds its own Canvas and shop panel from code. No manual UI setup required.
• Shop System: (Optional) Drag Shop Manager here, or it auto-finds.
• Creates a centered panel with "SHADOW MERCHANT" title, currency display, dynamically generated item rows with Buy buttons, and a close button. Items show 'SOLD' after purchase.
BossHealthBar.cs Empty GameObject (e.g. "Boss Health Bar") ⚙️ CODE-GENERATED — Builds its own Canvas and boss bar from code. No manual UI setup required.
• Creates a wide cinematic health bar at the top of the screen with boss name and crimson red fill. Shown/hidden via ShowBossBar(Health, string) and HideBossBar().
EnemyHealthBar.cs Enemy World-Space Canvas Placed on a child World Space Canvas situated above enemies. Link the child slider. Fades out automatically when uninjured.
NPCInteractable.cs NPC village GameObjects Requires Collider2D (check Is Trigger). Set NPC Name and write dialogue string array.
• Is Companion AI: Check for AI chatbot trigger.
• Is Shop Keeper: Check to launch the Shop UI after dialogue.
• Interact Prompt: (Optional) Drag visual prompt bubble (e.g. 'Press E').
NPCFacePlayer.cs NPC village GameObjects Flips NPC sprite to face the player when within range.
• Face Range: Detection distance (default 5).
• Use Sprite Renderer Flip: Check to flip sprite only (prevents mirroring child text). Uncheck to flip via Transform scale.
• Sprite Faces Right By Default: Set based on original sprite orientation.
• Invert Flipping: Check if NPC faces the wrong way.
PauseMenu.cs Empty GameObject (e.g. "Pause Manager") ⚙️ CODE-GENERATED — Builds its own Canvas and pause overlay from code. No manual UI setup required.
• Menu Scene Name: Scene to load on "Quit to Menu" (default "MainMenu").
• Creates full-screen dark overlay with Resume, Restart Level, and Quit to Menu buttons. Esc/P toggles. Respects active Dialogue/Shop/Companion panels.
ShopSystem.cs Shop Manager GameObject • Shop Items: Add items and set Name, Type (HealthBoost, DashUpgrade, ProjectileUnlock, HealingPotion), and Cost.
Manages item purchase validation and currency subtraction. Applies upgrades to player stats.
DialogueCompanionManager.cs Companion Chat Panel Link chat panel, dialogue text, message input, portrait image, and neutral/annoyed/explaining expression sprites. Coordinates with Flask chatbot server on port 5001.
CompanionTest.cs Test Object Debug utility script to test API connectivity to the local Ollama LLM endpoint.
AudioManager.cs Audio Manager GameObject • Persistent global Singleton (DontDestroyOnLoad).
• Music Source / SFX Source: AudioSource components for BGM and SFX.
• PlayBGM(AudioClip clip, bool fade): Plays music with smooth cross-fade volume interpolation.
• PlaySFX(AudioClip clip): Plays one-shot sound effects (combat, UI, hit reactions).
MainMenuController.cs Empty GameObject (e.g. "Main Menu") ⚙️ CODE-GENERATED — Builds its own Canvas and title screen from code. No manual UI setup required.
• Game Scene Name: Scene to load on "Play" (default "SampleScene").
• Click Sound / Title Music: Assign sound effects and the background music track to play when the menu is active.
• Visual & Text Customization: Exposes logoSprite, backgroundSprite (smoky background art asset), backgroundColor, buttonSize, font sizes, and bold settings directly in the Inspector.
• Creates a title screen with the smoky background, centered logo image, subtitle, divider lines, bottom ornament, and custom rounded bordered buttons (uses built-in 9-slice rounded sprite) that scale and glow on hover without horizontal stretching. Auto-deactivates upon gameplay start.
LevelMusicPlayer.cs Empty GameObject (e.g. "Level Music Player") • Level Music: Assign the gameplay music track to play when active gameplay starts.
• Checks MainMenuController.isPlaying to automatically suppress level music on the title screen and play it only when active gameplay starts.
IDamageable.cs N/A (Interface) Interface defining TakeDamage(int). Implemented by Health.cs and enemy scripts to standardize damage handling.
☁️ Environment & Visuals
CameraFollow.cs Main Camera • Target: Drag the Player transform. Handles smooth linear interpolation tracking of the character's movement.
ParallaxBackground.cs Background/Foreground Layers • Cam: Main Camera transform (auto-detects if empty).
• Parallax Effect X/Y: Scroll rates relative to camera (e.g., 0 = sky; 0.2-0.5 = distant; 1.0 = player level; 1.2+ = blurry foreground silhouette).
• Smoothing: Blend rate to eliminate camera-stutter (recommend 1.5 - 3.0).
• Auto Scroll Speed X/Y: Optional self-scrolling for moving clouds or fog.
• Infinite Horizontal Scroll: Automatically loops SpriteRenderer boundaries.
Cloud.cs Cloud Spawner / Clouds Moves background cloud graphics horizontally across the sky, fading and recycling them on borders.
fog.cs Fog Particle Overlay Slowly floats dark, ambient village fog visual overlays across the screen coordinates.
MoveAndFade.cs Popup Text Prefabs Moves floating numbers (like damage counts) upwards while fading out alpha transparency.
PlatformBase.cs Solid Level Platforms Base script for solid platforms. Exposes customizable dimensions and collision filters.
LevelGoalTrigger.cs Level End Trigger Volume ⚙️ CODE-GENERATED — Victory screen is built from code when the goal is triggered. No manual UI setup required.
• Requires BoxCollider2D (check Is Trigger).
• Victory SFX: (Optional) AudioClip victory jingle played on goal entry.
• Next Level Scene Name: Scene to load on "Next Level" (default "SampleScene").
• Main Menu Scene Name: Scene to load on "Main Menu" (default "MainMenu").
