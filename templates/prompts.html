🎮 Unity Parallax Script & Setup Guide

Step-by-Step Layering Setup

  1. Create parent GameObjects for each layer in your hierarchy (e.g., BG_0_Sky, BG_1_Mountains, Midground_Platforms, FG_Upclose_Vines).
  2. Set the sorting layers and order on the SpriteRenderer components to arrange them back-to-front (e.g. Sky order -10, Midground order 0, Foreground order 10).
  3. Attach ParallaxBackground.cs to each layer GameObject that needs parallax scrolling.
  4. Adjust the Parallax Coefficients in the inspector based on depth:
    • Far Background (Sky): X = 0, Y = 0 (locked to camera).
    • Misty Mountains: X = 0.2, Y = 0.05 (moves slowly).
    • Distant Village Houses: X = 0.5, Y = 0.1 (half speed).
    • Playable Level: No script needed (moves 1:1 with camera).
    • Foreground Silhouette Vines: X = 1.25, Y = 1.15 (scrolls faster than camera).
  5. Assign Smoothing = 2.5 to filter camera jitter. Enable limitVerticalOffset = true on mountain layers to clamp height drift.

Hollow Knight Aesthetic Rules

  • Foreground (Layer +10): Drawn as pure black silhouettes (no detail, solid color). Use standard or blur filters in Unity to give an out-of-focus feel.
  • Midground (Layer 0): Sharp, high-contrast, fully lit, and detailed. This is where action happens.
  • Background (Layer -5 to -15): Cool colors (slate blue, dark purple, teal). Blend layers with a Fog Particle System or translucent mist overlay to increase depth feel.
  • Auto-Scrolling Clouds: For the sky, add small auto-scrolling speed (e.g., AutoScrollSpeedX = 0.2) to simulate wind drift.
